# Changelog — MFW-DATABASE

## [7.6] — 2026-07-24

### Добавлено
- **Карточки локаций** — новая фича: при выборе конкретной локации в фильтре над списком рыб показывается карточка с уровнем разблокировки, стоимостью поездки, насыщением рыбой, загрязнением и количеством видов рыб на локации.
- **Фоновые изображения для всех 33 локаций** — собственные/лицензированные фотографии в стиле glassmorphism (полупрозрачная стеклянная панель поверх фото).
- Адаптивная вёрстка карточки локации — корректно отображается на мобильных экранах (`clamp()` для шрифтов, resize-safe панель, без переполнения текста).
- Статистика упоминаний рыб в обсуждениях сообщества (`mention_stats`) — частота локаций/наживок/крючков/дистанций по 131 виду, для справочного использования.
- Расширены данные по 98 видам рыб новыми записями о локациях/наживках/крючках (гайд Matvey Werty — 79 видов; скриншот-таблица из архива — 19 видов).
- Вычислены предварительные поля для всех 170 рыб: цена, доходность, диапазон крючка по весу, лучшая локация/наживка с альтернативами, кандидат на тег «Фарм».

### Исправлено
- Минимальный вес Щуки Травянки: 0.75 кг (было ошибочно занижено).
- Минимальный вес Чёрного Краппи: 0.2 кг (было ошибочно 2.685 кг).
- Названия локаций приведены к единому регистру: «Долина ветров», «Затерянное озеро», «Белые скалы» (было с заглавной буквы во втором слове).
- Убрана строка «Погода» из карточки локации (нерелевантна из-за изменчивости).

### Изменено
- Формула цены для рыб-монстров/лунных рыб подтверждена и зафиксирована: `Цена = round(p × Вес(кг) × 0.515)`.
- ⚠️ Формула цены для обычной рыбы остаётся **предварительной** (не подтверждена окончательно) — используется временная `192 + вес×0.022` / `236 + (вес−2000)×0.013158`.

### В работе / не завершено
- Переделка карточек рыб под новый формат (лучший вариант + альтернативы, крючок мин-макс, «Доходность» вместо «Стоимость») — данные готовы, вёрстка ещё не выполнена.
- Гипотеза о влиянии звёзд улова на цену — требует дополнительных калибровочных данных.
- Тег «💰 Фарм» — критерий определён, но не проставлен визуально в карточках.
