# Changelog — MFW-DATABASE

Версии по стандарту [Semantic Versioning](https://semver.org/): MAJOR.MINOR.PATCH.
- MAJOR — крупный структурный редизайн
- MINOR — новая функциональность
- PATCH — только исправление багов

Записи расположены от новых к старым.

## [7.8.0] — 2026-08-02

### Добавлено
- **Подтверждённые наживки** у 82 видов (172 наблюдения, распознаны с экранов поимки). Основная наживка по-прежнему берётся от сообщества, фактические добавлены в список альтернатив и выделены в карточке начертанием. Для приманок оставлен только лидер по числу поимок.
- **Фоновое фото локации на всей карточке рыбы** вместо одной лишь шапки; нижний блок параметров лежит на полупрозрачной подложке, как в карточках локаций.
- **Иконки валют** в карточках локаций: серебро для обычных поездок, золото для премиальных — вместо единого значка монеты.

### Установлено
- **Звёзды улова на цену не влияют.** Проверено на 606 группах «вид + одинаковый вес»: в 599 случаях цена совпала до монеты. Все семь расхождений объясняются удвоением за рекламу, трофейной надбавкой или ошибками распознавания. Гипотеза, висевшая с июля, закрыта.
- **Приманка задаёт диапазон вылавливаемого веса, а не конкретный вид** — как крючок. Для обычной рыбы правило выполняется в 100% случаев (124 наблюдения из 124), для монстров и лунных не действует.
- Внутри подходящего диапазона у видов есть предпочтения по приманке: Налим брал Choppo в 92% поимок при шести формально подходящих моделях.

### Исправлено
- **Данные и функции пересоздавались при каждой перерисовке списка**: 61 КБ объявлений находились внутри функции рендера. Вынесены в общую область.
- Канонизация названий кешируется — разбор одних и тех же строк повторялся для каждой карточки. Перерисовка ускорилась примерно в двадцать раз.
- Карточки вставляются в документ одним блоком вместо поэлементной вставки.
- Устранено расхождение между `MFWDB.json` и HTML: в одном было 69 формул, в другом 68.

## [7.7.0] — 2026-08-02

### Добавлено (новая функциональность)
- **Полный редизайн карточек рыб**: фоновое фото локации в шапке, название и локация, две независимые колонки — слева наживка / дистанция / крючок / поплавок, справа доходность / вес. Нижний блок параметров лежит на полупрозрачной подложке.
- **Логика «Фарм»**: список сортируется по показателю эффективности фарма (`farmScore`), а не по звёздам.
- **Флаг «без прилова» (`cleanCatch`)**: автоопределение через анализ пересечения диапазонов крючков по весу на одной локации+наживке. Бейдж «💰 ФАРМ» и цветная рамка карточки связаны с ним, а не только со старым статическим полем `note`.
- **Альтернативные локации и наживки** выводятся в карточке под основными.
- **Приведение названий к игровым**: разговорные и сокращённые формы из форумов, обсуждений и скриншотов сопоставляются с эталонными названиями, а не создают новые сущности — «ручейник» → «Личинка ручейника», «на изумрудном» → «Изумрудное озеро», «Живец маленький» → «Живец (маленький)». Латиница и названия брендов не искажаются.
- **Каталог снастей** (`gear_catalog.json`): 20 приманок с необходимым разрядом и диапазоном вылавливаемого веса, 21 крючок, 31 наживка — собран с внутриигровых скриншотов магазина.
- **Формулы цены в `MFWDB.json`**: поле `price_fit` (коэффициенты, R², число точек, диапазон калибровки, статус, источник) для 69 видов.

### Изменено
- ⚠️ **Формула цены пересмотрена: линейная вместо степенной.** Для откалиброванных видов действует `price = a + b × вес_кг`. Это отменяет утверждение из 7.6.3 о степенной формуле как окончательной — она остаётся приближённой оценкой для видов без калибровки.
- **Откалибровано 69 видов вместо 5**: 65 подтверждённых (R² > 0.99) и 4 предварительных. Данные собраны из личных скриншотов садка и экранов поимки — 2782 точки «вес → цена», накопленные за несколько прогонов распознавания.
- **Чёрный Краппи получил собственную формулу**. Прежнее допущение, что он делит формулу с Белым Краппи, не подтвердилось: расхождение достигает 10 монет и выходит за пределы погрешности.
- Закрыт **Окунь Речной** — раньше все известные экземпляры лежали в коридоре 3.10–3.19 кг, и наклон не определялся. С появлением экземпляров от 0.8 кг формула построена.
- В карточке выводится цена максимального экземпляра и статус формулы; за пределами диапазона калибровки значение помечается как экстраполяция.
- Названия локаций и наживок приведены к правилам русского языка для имён собственных: «Каменный берег», «Изумрудное озеро», «Кусок рыбы», «Личинка ручейника».
- Равнозначные варианты наживки пишутся через запятую («Медведка, Сыр»), обобщённое указание снасти — во множественном числе («Воблеры» = подойдёт любой воблер).

### Исправлено
- Альтернативная локация могла дублировать основную из-за расхождения регистра в данных («Изумрудное Озеро» / «Изумрудное озеро») — в базе было 35 таких расхождений.
- Скрытые дубли альтернатив: числовые суффиксы («Изумрудное озеро 2»), составные названия через слэш, обрезки составной наживки по разделителю, уточнения («Личинка ручейника 7.0 м»).
- Ошибочные названия приманок в данных сообщества: «Shake Head» → «Snake head», «Master» → «Master fish»; регистр «Predator PRO», «Big hunter», «Alpha diver».
- В `fish_catching_info.csv` починены 6 строк, где незакавыченная запятая в примечании ломала разбор файла.

### Инструменты
- **MFW-OCR** — приложение для распознавания игровых скриншотов: извлекает вид, вес, цену и наживку, накапливает наблюдения между прогонами, строит линейные модели цены устойчивым методом и вписывает их в базу.
- **Копилка наблюдений**: точки из разных прогонов складываются в один пул с отсевом дубликатов. Виду, у которого сегодня одна точка, а завтра вторая, больше не нужно, чтобы обе попали в один прогон.
- Черновик `fish_catching_info.csv` пополнен 353 агрегированными записями; у 249 прежних строк пересчитан диапазон весов по правилу бегущего диапазона.

### Примечание
Цены из скриншотов садка пригодны для калибровки. Прежнее сомнение вызывали два артефакта: иконка монеты прилипала к числу при распознавании, а трофейные экземпляры продаются ровно на +50% дороже.

## [7.6.3] — 2026-07-25

### Изменено
- Формула цены для обычной рыбы принята единой для всех типов (обычные/монстры/лунные):
  `Коэфф = 31.85 × (Вес/МаксВес × 100)^(−0.8968)`, `Цена = round(Коэфф × p × Вес_кг)`.
  Подтверждено на 169 калибровочных точках, медиана коэффициента при весе, близком к максимуму вида — 0.52.
  ⚠️ **Устарело в 7.7.0**: для откалиброванных видов цена линейна по весу. Степенная формула сохраняется только как приближение для видов без собственной калибровки.
- Пересчитаны предварительные цены (`price_final`) для всех 170 рыб.

### Добавлено
- Интегрирована таблица «Рыбы по локациям» (vk@alone_with_himself, 15.12.2022) — 157 записей: локация, наживка, дистанция, крючок, вес, цена, опыт, отметки о прилове и трофее.
- 8 лунных рыб (Кинста, Трафальгар, Панзерус, Карин, Газилиус, Виена, Скрумпер, Зой) получили точную наживку, дистанцию и глубину проводки.
- `MFWDB.json` добавлен в репозиторий как структурированный источник данных (170 рыб, 729 записей `community_reports`).

### Примечание
Изменения только в данных и документации. Файл `MFW-DATABASE-v7.6.2.html` не менялся.

## [7.5.0] — 2026-07-23

### Добавлено
- Карточки локаций: уровень разблокировки, стоимость поездки, насыщение рыбой, загрязнение, список рыб.

- Статистика упоминаний рыб в обсуждениях сообщества (`mention_stats`) по 131 виду.
- Записи о локациях/наживках/крючках для 98 видов.
- Вычисленные поля для всех 170 рыб: цена, доходность, диапазон крючка, лучшая локация/наживка с альтернативами, кандидат на тег «Фарм».

### Исправлено
- Минимальный вес Щуки Травянки: 0.75 кг (было занижено).
- Минимальный вес Чёрного Краппи: 0.2 кг (было ошибочно 2.685 кг).
- Названия локаций приведены к единому регистру.
- Убрана строка «Погода» из карточки локации (нерелевантна из-за изменчивости).

### Изменено
- Формула цены для монстров и лунных рыб: `Цена = round(p × Вес(кг) × 0.515)` — подтверждена на 26 видах из 26, коэффициент 0.515 ± 0.009.
  ⚠️ **Устарело в 7.7.0** для видов с собственной калибровкой.
- Гипотеза о едином коэффициенте `p × вес × 0.52` для всех рыб опровергнута: для обычной рыбы она не подтвердилась (Щука Травянка на 1 и 3 кг давала разные коэффициенты).

### Источники данных этой версии
- Скриншоты локаций (33 фото) — уровни разблокировки 32 локаций и Луны.
- Скриншоты крючков, наживок и блёсен (118 фото) — таблица «крючок → диапазон веса» (20 позиций, #1.1–#6.3) и весовые классы наживок (31 позиция).
- Текстовый гайд сообщества (Matvey Werty, 11.09.2024) — локация, наживка, дистанция и крючок для 79 видов.
- Таблица `MFW_VK114` — те же поля для 19 видов (Пайяра, Ротан, Скорпена, Сазан, Синец, Хариус, виды щук).
- Архив обсуждения (120 HTML-страниц) — 402 упоминания по 131 виду.
- Итог: 402 записи `community_reports`, покрытие 170 видов из 170 — белых пятен нет.

### Известные ограничения на момент версии
- Статистика упоминаний по отдельным видам (например, Сом) недостоверна и не должна использоваться для выбора «лучшей» локации без ручной проверки. *Актуально до сих пор.*
