# My Fishing World — Database

**База данных по рыбе и трофеям** для мобильной игры My Fishing World.

Текущая версия: **7.7.0**

## Что внутри

Интерактивная HTML-страница (`MFW-DATABASE-v7.7.0.html`) с данными по 170 видам рыб и 33 локациям, плюс структурированные источники данных `MFWDB.json` и `gear_catalog.json`:

- **Карточки рыб**: локация (с фоновым фото), наживка, дистанция, крючок, поплавок, вес, редкость, флаги «монстр»/«лунная рыба», доходность
- **Карточки локаций**: уровень разблокировки, стоимость поездки в серебре или премиальной валюте, насыщение рыбой, загрязнение, список обитающих видов — с фоновыми фотографиями
- **Точные формулы цены** для 69 видов: цена рыбы линейна по её весу, коэффициенты откалиброваны по личным скриншотам
- **Каталог снастей**: 20 приманок с необходимым разрядом и диапазоном вылавливаемого веса, 21 крючок, 31 наживка
- Фильтры: список А-Я (с переключением направления сортировки), фарм, монстры, коллекция, ночная рыба, поиск по локации/наживке/крючку/дистанции

## Как пользоваться

Просто сохраните [`MFW-DATABASE-v7.7.0.html`](https://github.com/Deathstalkerrr/My-Fishing-World-Database.github.io/blob/main/MFW-DATABASE-v7.7.0.html) у себя на устройстве, в любом удобном для вас месте, и откройте в браузере — все данные и стили встроены в один файл, интернет не нужен.

Если нужна онлайн версия, то её вы найдёте здесь: [https://deathstalkerrr.github.io](https://deathstalkerrr.github.io/)

## Источники данных

Собрано и систематизировано на основе:
- Официальной внутриигровой базы (локации, крючки, редкость)
- Обсуждения сообщества игроков во ВКонтакте (402+ наблюдения)
- Таблицы Михаила Куликова «Рыбы по алфавиту» (170 видов)
- Текстового гайда сообщества (79 видов: локация/наживка/дистанция/крючок)
- Личных скриншотов садка и экранов поимки — 2782 точки «вес → цена», распознанные автоматически
- Внутриигровых скриншотов магазина (приманки, крючки, наживки: разряды и диапазоны веса)

## Формула цены

Цена рыбы линейна по весу, у каждого вида свои коэффициенты:

```
Цена = a + b × Вес(кг)
```

Свободный член `a` — плата за сам факт поимки. Из-за него «цена за килограмм» непостоянна и падает с ростом веса: у Щуки Травянки она меняется от 239 монет за кг при 0.75 кг до 80 при 3.15 кг.

Коэффициенты для 69 видов хранятся в `MFWDB.json` (поле `price_fit`) вместе с диапазоном весов, на котором они откалиброваны. За пределами этого диапазона значение в карточке помечается как экстраполяция.

Для остальных видов используется приближённая оценка — до появления достаточного числа наблюдений.

## Известные ограничения

- Точные формулы есть для 69 видов из 170. Остальным не хватает наблюдений: чаще всего все известные экземпляры вида оказываются примерно одного веса, а для построения линейной модели нужны экземпляры разного размера
- Гипотеза о влиянии «звёзд» улова на цену — не подтверждена окончательно
- Статистика упоминаний по отдельным видам (например, Сом) недостоверна и не должна использоваться для выбора «лучшей» локации без ручной проверки
