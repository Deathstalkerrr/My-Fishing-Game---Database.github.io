###  [`My Fishing World — Database`](https://deathstalkerrr.github.io/)

**База данных по рыбе и трофеям** для мобильной игры My Fishing World.

Текущая версия: **7.6.3**

## Что внутри

Интерактивная HTML-страница (`MFW-DATABASE-v7.6.2.html`) с данными по 170 видам рыб и 33 локациям, плюс структурированный источник данных `MFWDB.json`:

- **Карточки рыб**: локация, наживка, дистанция, крючок, вес, редкость, флаги «монстр»/«лунная рыба», доходность
- **Карточки локаций**: уровень разблокировки, стоимость поездки, погода, насыщение рыбой, загрязнение, список обитающих видов — с фоновыми фотографиями
- Фильтры: список А-Я (с переключением направления сортировки), фарм, монстры, коллекция, ночная рыба, поиск по локации/наживке/крючку/дистанции

## Как пользоваться

Просто сохраните [`MFW-DATABASE-v7.6.2.html`](https://github.com/Deathstalkerrr/My-Fishing-World-Database.github.io/blob/main/MFW-DATABASE-v7.6.2.html) у себя на устройстве, в любом удобном для вас месте, и откройте в браузере — все данные и стили встроены в один файл, интернет не нужен.

Если нужна онлайн версия, то её вы найдёте здесь: [https://deathstalkerrr.github.io](https://deathstalkerrr.github.io/)

Тем, кому нужна онлайн-версия — она доступна по адресу: [https://deathstalkerrr.github.io](https://deathstalkerrr.github.io/)

## Источники данных

Собрано и систематизировано на основе:
- Официальной внутриигровой базы (локации, крючки, редкость)
- Обсуждения сообщества игроков во ВКонтакте (302+ наблюдений)
- Таблицы Михаила Куликова «Рыбы по алфавиту» (170 видов)
- Текстового гайда сообщества (79 видов: локация/наживка/дистанция/крючок)
- Личных скриншотов калибровки цены (подтверждена формула для рыб-монстров/лунных рыб)

## Известные ограничения

- ✅ ~~Формула цены для обычной рыбы~~ — **финализирована в v7.6.3**, подтверждена на 169 калибровочных точках
- Тег «Фарм» — критерий определён, но визуально ещё не проставлен во всех карточках
- Гипотеза о влиянии «звёзд» улова на цену — не подтверждена окончательно
- **Карточки рыб ещё не переделаны** под новый формат (лучший вариант локации/наживки + альтернативы, диапазон крючка мин-макс, «Доходность» вместо «Стоимость») — данные для этого уже посчитаны, но вёрстка не выполнена

Подробности — в `CHANGELOG.md` и `PATCH_NOTES_v7_5.md`.
