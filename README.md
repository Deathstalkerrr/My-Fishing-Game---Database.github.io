# My Fishing World — Database

**База данных по рыбе и трофеям** для мобильной игры My Fishing World.

Текущая версия: **7.7.0**

## Что внутри

Интерактивная HTML-страница (`MFW-DATABASE-v7.7.0.html`) с данными по 170 видам рыб и 33 локациям, плюс структурированные источники данных `MFWDB.json` и `gear_catalog.json`:

- **Карточки рыб**: локация, наживка, дистанция, крючок, вес, редкость, флаги «монстр»/«лунная рыба», доходность
- **Карточки локаций**: уровень разблокировки, стоимость поездки, погода, насыщение рыбой, загрязнение, список обитающих видов — с фоновыми фотографиями
- Фильтры: список А-Я (с переключением направления сортировки), фарм, монстры, коллекция, ночная рыба, поиск по локации/наживке/крючку/дистанции

## Как пользоваться

Просто сохраните [`MFW-DATABASE-v7.7.0.html`](https://github.com/Deathstalkerrr/My-Fishing-World-Database.github.io/blob/main/MFW-DATABASE-v7.7.0.html) у себя на устройстве, в любом удобном для вас месте, и откройте в браузере — все данные и стили встроены в один файл, интернет не нужен.

Если нужна онлайн версия, то её вы найдёте здесь: [https://deathstalkerrr.github.io](https://deathstalkerrr.github.io/)

## Источники данных

Собрано и систематизировано на основе:
- Официальной внутриигровой базы (локации, крючки, редкость)
- Обсуждения сообщества игроков во ВКонтакте (302+ наблюдений)
- Таблицы Михаила Куликова «Рыбы по алфавиту» (170 видов)
- Текстового гайда сообщества (79 видов: локация/наживка/дистанция/крючок)
- Личных скриншотов садка и поимок (267 точек «вес — цена», калибровка формул для 16 видов)
- Внутриигровых скриншотов магазина (20 приманок, 21 крючок, 31 наживка — разряды и диапазоны веса)

## Известные ограничения

- ✅ ~~Формула цены для обычной рыбы~~ — **уточнена в v7.7.0**: цена линейна по весу (`price = a + b × вес_кг`). Точные формулы откалиброваны для 16 видов; для остальных используется приближённая оценка
- ✅ ~~Тег «Фарм»~~ — **проставлен в v7.7.0**, вычисляется автоматически по флагу `cleanCatch`
- ✅ ~~Карточки рыб ещё не переделаны~~ — **переделаны в v7.7.0**
- Точные формулы цены действуют внутри диапазона весов, на котором калибровались; за его пределами значение помечается как экстраполяция
- Гипотеза о влиянии «звёзд» улова на цену — не подтверждена окончательно
